# Push-уведомления My Garage

Push требуют HTTPS и работающего Node.js-сервера. На iPhone сайт нужно сначала
добавить на экран «Домой» и открыть как приложение. Обычная вкладка Safari на
iPhone не может подписаться на веб-push.

## Подготовка сервера

Нужен Node.js 18 или новее. В каталоге сайта установи зависимости:

```powershell
npm install
```

Скопируй `.env.example` в `.env`, сгенерируй VAPID-ключи и добавь значения в
`.env`:

```powershell
node -e "console.log(JSON.stringify(require('web-push').generateVAPIDKeys(), null, 2))"
```

- `publicKey` запиши в `VAPID_PUBLIC_KEY` и в `pushApplicationServerKey`
  в `index.html`. Это публичный ключ — приложение использует его для создания
  подписки (если сервер доступен, ключ берётся с сервера автоматически, а
  значение в `index.html` служит запасным).
- `privateKey` запиши **только** в `VAPID_PRIVATE_KEY`. Приватный ключ нельзя
  вставлять в `index.html` и публиковать.
- В `VAPID_SUBJECT` укажи действующий адрес владельца сайта
  (например, `mailto:you@example.com`).
- Для `ADMIN_TOKEN` создай длинный случайный секрет.
- В `ALLOWED_ORIGINS` перечисли через запятую адреса сайтов, с которых
  приложение обращается к серверу (по умолчанию `https://zaibat228.github.io`).

Не публикуй `.env` и приватный VAPID-ключ. Если ключи когда-либо попадали в
публичный репозиторий, сгенерируй новые: при следующем открытии приложение само
переподпишется с новым ключом.

Запусти сервер командой:

```powershell
npm start
```

Для разработки открой `http://localhost:3000`. Для доступа с устройств
публикуй сайт через HTTPS reverse proxy или Node.js-хостинг. Если proxy
завершает TLS, укажи для `HOST` адрес интерфейса, доступного proxy, а сам
`server.js` не выставляй напрямую в публичный интернет без HTTPS.

Проверить, что сервер работает: `GET /api/health` — ответ `{"ok":true,...}`.

Файл подписок по умолчанию хранится в `data/subscriptions.json`. На хостинге
укажи для `DATA_DIR` постоянный каталог вне публичной директории сайта и
настрой резервное копирование с ограниченным доступом.

## Обновление сайта

Заменив файлы проекта, перезапусти сервер: `Ctrl+C`, затем `npm start`.
Уже запущенный процесс продолжает работать со старым `server.js` — например,
старая версия не отдаёт `app.css`, и сайт открывается без оформления.
На Render после загрузки файлов в репозиторий дождись нового деплоя или
нажми **Manual Deploy → Deploy latest commit**.

## Render (бесплатный тариф)

- Переменные из `.env` задай в настройках сервиса (Environment). `HOST` не
  указывай — сервер слушает `0.0.0.0`, а `PORT` Render задаёт сам.
- Бесплатный сервис засыпает через 15 минут без входящих запросов. Пока он
  спит, планировщик не работает и напоминания не отправляются. Чтобы сервер
  не засыпал, настрой внешний пинг (например, cron-job.org или UptimeRobot)
  каждые 10–14 минут на адрес
  `https://my-garage-push.onrender.com/api/health`.
  Один постоянно работающий сервис укладывается в 750 бесплатных часов в месяц.
- Файловая система бесплатного сервиса временная: при перезапуске или новом
  деплое `data/subscriptions.json` очищается. Приложение заново отправляет
  подписку на сервер при каждом открытии, поэтому после перезапуска
  уведомления восстановятся, когда пользователь откроет приложение. Для
  надёжного хранения подключи постоянный диск и укажи его в `DATA_DIR`.

## Напоминания и тихие часы

Напоминания отправляются раз в 3 часа, начиная через 3 часа после включения
уведомлений. По умолчанию с 22:00 до 9:00 по времени устройства подписчика
напоминания не приходят (настройка «Не беспокоить ночью» в приложении).
Часовой пояс приложение передаёт само; если он неизвестен, используется
`DEFAULT_TIME_ZONE` из `.env` (по умолчанию `Europe/Moscow`).

## Уведомление об обновлении

После публикации новой версии владелец сайта отправляет подписчикам объявление
об изменениях:

```powershell
$headers = @{ Authorization = "Bearer $env:ADMIN_TOKEN" }
$body = @{
  title = "My Garage обновлён"
  body = "Добавлены новые возможности."
  url = "/"
} | ConvertTo-Json
Invoke-RestMethod -Method Post `
  -Uri "https://your-domain.example/api/push/notify-update" `
  -Headers $headers -ContentType "application/json" -Body $body
```

`url` указывается относительно папки приложения: `/` откроет главную страницу
приложения и на GitHub Pages. Объявление получают только подписчики,
включившие уведомления о новых версиях. Тихие часы на объявления не действуют.

Подписки и расписание напоминаний привязаны к этому серверу. Несколько
экземпляров Node.js без общего хранилища и единственного планировщика
использовать нельзя: это приведёт к повторным уведомлениям.
